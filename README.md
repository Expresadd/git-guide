# Шпора git

## Создание и подключение репозитория:

```bash
 #Создаем репозиторий на гитхаб (кнопка new)
 git config --global init.defaultBranch main
 git init
 #Создаем и коммитим первый файл
 git remote add origin <ссылка на репозиторий>
 git push -u origin main
```

## Просмотр файлов:

```bash
ls .git #просмотр файлов
cd <файл> #файл, к которому хотим перейти
cd #выйти из всех вайлов
```

## Pull requests:

```bash
git push -u origin <название ветки>
Затем, заходим на гитхаб -> pull requests -> New pull request (зеленая кнопка)
Выбираем, куда мы хотим слить изменения: например, base: master <- compare: feat-header (то есть из feat-header в master)

Чтобы подтянуть изменения из гитхаба пишем: git pull
Чтобы подтянуть изменения из основной ветки в другую, пишем в дочернюю: git rebase <название основной ветки>

git merge <название ветки, из которой нужно подтянуть файлы> - слияние файлов
Если было неудачное слияние файлов, которое нужно было попровлять, то
исп после исправлений: git merge --continue
```

## Перезапись последнего коммита:

```bash
git commit --amend
```

## Перемещение по коммитам:

```bash
git checkout <хеш коммита>  #перемещает на определенный коммит

git switch - или git checkout ORIG_HEAD #перемещает на последний коммит
```

## Отмена (удаление) коммита:

```bash
git revert <хеш коммита>
git push
```

## Возврат к определенному коммиту и изменение его:

```bash
git reset --soft <хеш коммита, к которому нужно вернуться>
#меняем код
git push -f #или git push --force
```

## Откат до определенного коммита:

```bash
git restore --source <хеш коммита> <название файла> #например, index.html
```

## Изменили код, но хотим откатить изменения:

```bash
git restore .
```

## В одной ветке дописали код, хотим перенести коммит и в другую:

```bash
git cherry-pick <хеш коммита>
```

## Удаление и восстановление удаленного файла:

```bash
rm <имя файла> #удалить файл
 git restore <имя файла> #восстановить удаленный файл
 Если файл находится в индексе (добавили с помощью git add...), то возвращаем с помощью: git restore --staged <имя файла>
```

## Решение проблем:

```bash
 Если создать новый файл, изменить уже созданиый, а замет сразу написать коммит для всего коммандой git commit -am "..." и сделать git push, то новый файл не создается на гитхабе, поэтому после этого нужно написать в git bash: git add -A, затем git commit --amend, который поможет перезаписать последний коммит, затем git push -f
```
